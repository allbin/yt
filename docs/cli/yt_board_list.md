## yt board list

List agile boards

### Synopsis

List the agile boards shared with you, with their projects and current
sprint. YouTrack leaves out a board private to its owner even when you can
open it; give that board to "yt board" by id or URL.

```
yt board list [flags]
```

### Examples

```
  yt board list
  yt board list --json
```

